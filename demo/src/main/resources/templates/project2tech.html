Projekt 2: Persönliches Web-Portfolio

Dieses Portfolio ist eine Spring-Boot-Anwendung: Thymeleaf rendert die Seiten aus gemeinsamen Layout-Fragmenten (Head, Navigation, Footer), statische Dateien liefert der eingebettete Server direkt aus. Gebaut mit Java 21 und Gradle.

Das Frontend kommt bewusst ohne Framework aus: handgeschriebenes HTML, CSS und JavaScript mit responsivem Layout vom Smartphone bis zum Desktop, eigenem Cursor, Scroll-Animationen per IntersectionObserver und Glassmorphism-Design.

Die Inhalte gibt es in drei Sprachen (DE/EN/FR): Die Texte liegen in JSON-Dateien und werden clientseitig eingesetzt; die Sprache folgt der Browsereinstellung und lässt sich jederzeit wechseln, fehlende Übersetzungen fallen auf Englisch zurück.

Auf Performance und Barrierefreiheit habe ich geachtet: Bilder als WebP (74 MB → 3 MB), Unterstützung für reduzierte Bewegung, per Tastatur bedienbare Elemente und SEO-Grundlagen wie Meta-Tags, Sitemap und Open Graph.
